# kube_prometheus role

Installs [Prometheus Operator](https://prometheus-operator.dev/docs/getting-started/installation/#install-using-kube-prometheus) to collect [Numaflow metrics](https://numaflow.numaproj.io/operations/metrics/metrics/#prometheus-operator-for-scraping-metrics). This role assumes that the prerequisites described in the [kube-prometheus README](https://github.com/prometheus-operator/kube-prometheus#prerequisites) are already met.
